# GEO-1 요약 — G2(xTB) TS → 라벨 TS 구조 보정 (Uni-Mol+ 방식)

1. 시험 fold 0–4 전체(D1, G2 입력 8,425반응, 같은 형태 para 기준 짝 840개)에서 주 지표(쌍 형성 결합 오차 ≤ 0.005 Å인 비율)는 G2 그대로 0.160 → 모델 0.364이고, 차이의 core bootstrap 95 % CI는 [+0.140, +0.269]다.
2. 판정은 **부분**이다(명령서 12절). 차이의 CI 하한은 0보다 크지만, 비율이 통과 기준 0.5에 못 미친다.
3. D0는 도움이 됐다. D0를 빼고 학습하면 0.276으로 내려가고, 모델과의 차이 CI는 [+0.048, +0.132]다.
4. D0-G2 계산은 5,260반응 중 4,488개(85.3 %)가 성공했고, 7,201코어시간이 들었다.

## 시작 조건

- 기준: 사용자가 지운 `origin/d1-g3l` 대신 `origin/d1-g3` aa4399bf에서 `geo1` 브랜치를 만들었다(결정 0-base).
- 디스크: 시작 때 258/300 GB였다. G1 폴더는 지우지 않았다(결정 g1 보존).
- GPU 환경: env_d1fu2(Python 3.11, torch 2.2.1+cu118, numpy 1.26). D1 실행 환경은 numpy 2.0이라 pickle을 서로 맞게 읽도록 했다(결정 U-0).

## Phase D — 학습 데이터

- 기록 14,526개(D0 5,260 + D1 9,266). same_ts 판정을 무작위 300반응으로 다시 확인해 모두 같았다.
- D0와 D1에서 같은 반응(입체 정보를 뺀 정규화 SMILES)은 5개로, D0에서 뺐다(결정 D-1).

## Phase U — 검사

- 합성 데이터 검사 U-1–U-7s는 모두 통과했다(회전·거울 불변, 거리 계산, 가짜 궤적 비율 q = 1 10 %, q = 0 80 %).
- 실제 데이터: U-0(14,526), U-8(G2 그대로 재현: 840짝, 비율 0.1595, 중앙값 0.0155 Å), U-9 통과.
- U-7(32개 과적합 시험)은 기준(손실 비율 < 0.5)을 넘지 못했다(0.73). 사용자 방침대로 진행했다(결정 U-7).
  - 진단(U7_diag.json): 학습률 1e-3으로 8,000 step 돌리면 0.41로 기준을 넘는다. 학습 단계 수가 모자랐던 것이다.

## Phase R — 학습

- 사용자 결정 R-user: 300 epoch, 조기 종료 없음, 처음부터 다시 학습.
- 진행 중 바꾼 것(모두 DECISIONS.md):
  - R-once, R-lpt: launcher가 실행 자리를 차지하지 않게 하고, 준비된 job 가운데 오래 걸리는 것부터 냈다.
  - **R-select:** 300번의 검증 중 한 epoch 최댓값 대신 11 epoch 창 평균이 가장 좋은 창의 가운데 epoch로 설정과 epoch를 골랐다. 튀는 값을 피하기 위해서이며, 고른 뒤에야 시험 결과를 봤다.
- 학습 곡선(R_curves_interim.json, 끝난 tune 4개 분석): 반응 중앙 형성 오차는 약 110–130 epoch부터 평평하고, 학습 손실은 그 뒤에도 절반으로 줄었다. 학습 길이보다 일반화가 한계다.

| fold (내부 검증 = D1 fold) | G2 그대로 | c0 | c1 | c2 | c3 | 선택 (epoch) |
|---|---|---|---|---|---|---|
| 0 (1) | 0.203 | 0.365 | 0.290 | 0.319 | **0.367** | c3 (196) |
| 1 (2) | 0.198 | **0.454** | 0.417 | 0.428 | 0.354 | c0 (287) |
| 2 (3) | 0.218 | **0.333** | 0.299 | 0.290 | 0.211 | c0 (203) |
| 3 (4) | 0.100 | 0.180 | 0.204 | 0.190 | **0.213** | c3 (133) |
| 4 (0) | 0.087 | 0.176 | 0.153 | **0.208** | 0.194 | c2 (146) |

- 값은 내부 검증의 주 지표(11 epoch 창 평균)다. c0·c2는 반복 1회(R = 1), c1·c3는 3회이고, c2·c3는 가짜 궤적 잡음이 크다(σ 0.20 Å).
- 설정이 fold마다 달라, 반복 횟수나 잡음 크기 중 어느 쪽이 일관되게 낫지는 않았다.

## 판정 (명령서 12절, 결과 보기 전에 고정)

- 통과: 비율 ≥ 0.5이고 CI 하한 > 0 / **부분: CI 하한 > 0이지만 비율 < 0.5** / 실패: CI 하한 ≤ 0
- 결과: 비율 0.364, CI 하한 +0.140 → **부분**.

## 한계

- **다른 형태 G2는 학습하지 않았다**(명령서 9-1). 시험에는 넣었고, different 분류의 비율(0.125)이 낮다.
- **정밀도 바닥:** 라벨 방법 그대로 재최적화해도 0.0036 Å 차이가 난다(D1-G3L-C). 기준 0.005 Å에 가까워, 비율이 오를 수 있는 폭에 한계가 있다.
- **Gaussian(D0)과 ORCA(D1)의 B3LYP 정의 차이**를 출처 표시(src 토큰)로만 흡수했다.
- **에너지 단계는 하지 않았다.**
- 그 밖:
  - 설정·epoch는 내부 검증 한 번(seed 0)으로 골랐다. 설정 사이 차이가 검증 잡음과 비슷하다(fold 0의 c3 0.367 대 c0 0.365).
  - R-select 규칙(11 epoch 창)은 끝난 tune 곡선을 본 뒤 바꿨다. 시험 결과를 보기 전이었다.
  - U-7 과적합 시험은 명령서 기준(2,000 step)을 넘지 못했다. 8,000 step에서는 넘는다.
  - 무거운 원자 RMSD는 바뀌지 않았다(0.81 → 0.80 Å).
- 다음 단계(에너지)는 사용자 지시를 기다린다. 사용자가 GEO2 명령서를 주었고, Phase Y는 사용자 지시로 이미 시작했다(GEO2 DECISIONS Y-early).
