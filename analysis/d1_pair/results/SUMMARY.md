# D1PAIR rev 9 — 요약

D0 4,963행(라벨 5,265행 중)으로 학습해 고정한 단일 반응 모델 f0와 D1 짝으로 학습한 차이 모델 g를 더한 arm B로, 처음 보는 (dipole, 골격) 조합(core 5-fold T1, 평가 core 44개, 시험 기준 짝 6,885개)에서 작용기 X를 바꿀 때의 ΔΔ를 장벽과 8채널마다 예측했다.
주 비교 9개(8채널 + 직접 장벽)에서 B는 모두 A(f0 차이만)보다 MAE가 낮았다(차이 0.160–2.62 kcal/mol, 95 % CI 하한 모두 > 0, Holm p 모두 0.0090, 5개 fold 모두 B가 낮음).
단계 판정: 단계 0은 9개 타깃 모두 통과, 단계 1(R²_fam 중앙값 ≥ 0.5)은 barrier·elst·pauli·cpcm 4개만 통과, 단계 2(oi·cpcm 꺾임 판별)는 둘 다 실패.

덧붙여, 결과를 본 뒤 세운 "C(g만, f0 없음)가 B보다 낫다"는 가설을 아직 보지 않은 LODO·LOSO에서 확인했다(ADD1 A-2). 18개 중 17개가 확증됐고(Holm p < 0.05, CI 하한 > 0), LODO disp 하나만 확증되지 않았다.
T2(V를 본 적 없는 모델)는 사용자 결정으로 중단해 결과가 없다(D-1).

수치는 모두 `results/` 파일에서 옮겼다. 주 비교는 `E_primary_tests.csv`, 단계 판정은 `E_stages.csv`, 지표는 `E_metrics.csv`, 꺾임은 `E.json` `bend_rates_T1`, 부 비교는 `E_secondary_tests.csv`, ADD1 확증은 `E_add1_tests.csv`, 행 흐름은 `E_data_flow.csv`·`G_by_reason.csv`에 있다.
사양: `docs/specs/D1PAIR_REV9.md`. 사전 등록: `PREREG_D1PAIR.md`(commit 10f99d8d, 학습 전), 추가본 `PREREG_D1PAIR_ADD1.md`(commit 1de89a0f, LODO·LOSO 평가 전).
반올림: MAE 소수 둘째(disp·cds·c_ghost는 셋째), R² 셋째, p 유효숫자 둘. 단위는 kcal/mol, Hammett 값과 ρ는 log 단위(−ΔΔ/1.3642).

- **LODO(dipole 하나를 통째로 뺌):** B 대 A의 차이가 barrier·d1·cds에서 사라진다. 오차도 크게 는다. B의 MAE는 T1 → LODO로 barrier 0.65 → 1.51, d1 0.59 → 1.25, oi 1.40 → 2.51이다.
  X가 붙은 분자가 학습에 없는 R1 짝(4,612짝)만 보면 barrier·d1·oi·cds에서 B 대 A 차이가 없다.
- **LOSO(골격 하나를 뺌):** T1과 거의 같다. B의 MAE는 barrier 0.65, d1 0.56, oi 1.41이다. R2 짝(2,273짝)에서도 10개 모두 B < A다. 처음 보는 dipole이 처음 보는 골격보다 훨씬 어렵다(`figures/fig6_lodo`).
- **Σ장벽 대 직접 장벽(B):** 9개 채널 예측의 합은 MAE 0.85, 직접 예측은 0.65로, 직접 예측이 0.20(0.13, 0.27) 낫다.
- **모델별(arm B, T1):** 시험 MAE가 가장 낮은 모델은 10개 타깃 모두 SVR이고, 대표 모델(안쪽 CV)과 같다. KRR − SVR은 0.005–0.10이고 d1·elst만 CI가 0을 포함한다. Ridge는 모든 타깃에서 가장 나쁘다. 150개 비교 전체는 `E_secondary_tests.csv` `model pair (B)`에 있다.
- **민감도:** P_sens(hygiene로 뺀 68짝을 다시 넣은 6,953짝)와 D0 겹침을 뺀 6,706짝에서도 B 대 A 결론은 같다. 차이는 주 결과와 0.04 kcal/mol 안에서 같다(가장 큰 것은 pauli, D0 겹침 제외에서 0.035).

## 11. 한계

- **구조 출발점이 DFT TS다.** G1은 DFT TS에서 출발한 xTB 구조라, SMILES에서 시작하는 예측이 아니다.
- **채널 값은 관측량이 아니다.** EDA 분해 방식(B3LYP-D3(BJ)/def2-TZVP SMD(water), 단편 정의)에 따른 양이다.
- **같은 반응물 분자가 여러 core에 나온다**(7,249/7,253짝). T1의 일반화는 분자가 아니라 조합에 대한 것이다. X가 붙은 분자를 빼는 LODO R1 짝에서는 barrier·d1의 B 대 A 이득이 사라진다.
- **숨은 V는 6계열(5개가 nitrone)뿐이다.** 그나마 T2를 돌리지 않아 V 일반화는 T1의 16건 사례로만 말할 수 있다.
- **실패·되살림 행이 있다.** G1 실패 226행이 빠졌고, 그 가운데 2개 core는 기준 짝을 모두 잃었다. 되살린 66행은 첫 시도와 다른 사다리 단계(제약 사전 최적화, 모드 변위, 정확한 Hessian 등)로 얻은 구조다. feature 실패 96행도 빠졌다.
- **모델별 반대칭 구현이 다르다.** Ridge는 Δx만 쓴다(x̄ 상호작용 없음). KRR·SVR은 반대칭 커널을 쓰고, SVR은 짝을 양방향으로 학습해 예측을 반대칭화한다. XGB는 양방향 학습 후 반대칭화하고, NN은 공유 부분망의 차이를 쓴다. 모두 gate M-1을 통과했지만(최대 위반 0.0) 표현력이 다르다.
- **cds·c_ghost는 짝 안 변화가 매우 작다.** para·meta에서 B가 0 예측보다 나쁘거나 같다. R²_fam은 음수다.
- **f0는 D1에서 크게 빗나간다.** A가 10개 중 8개 타깃에서 0 예측보다 나쁘다. arm B의 이득은 대부분 g가 이 차이를 보정한 것이고, ADD1이 보여 주듯 f0를 빼는 쪽(C)이 더 낫다.
- **처음 보는 dipole(LODO)에서는 오차가 크게 는다**(barrier 1.51, oi 2.51 kcal/mol). 단계 2 기준과는 거리가 멀다.

## 13. 재현

코드는 `analysis/d1_pair/`, scratch는 `/gpfs/tmp_cpu2/yeseo1ee/d1_pair`(`$D1PAIR_SCRATCH`)다. 모든 명령은 `sbatch`로 돌린다.

- **잡 스크립트:**

- **순서:** 각 스크립트 머리 주석에 사용법이 있다.
  1. Phase 0/P: `d1_extract_jobs.py run` → `d1_phase_p.py run` → `stereo` → `inputs`
  2. G: `d1_g1.py prep` → `g0` → `run i n` → `summary` → `d1_recover.py run i n` → `summary`

  4. F0: `d1_f0.py fit i n` → `report` → `predict i n` → `collect`
  5. S: `d1_split.py build` → `prereg`, 그리고 commit
  6. M: `bash jobs/submit_M.sh`(NN·grid·PB·SVR array → `d1_train.py collect` → `d1_eval.py all ::: d1_figures.py`, SLURM 의존성 사슬)
