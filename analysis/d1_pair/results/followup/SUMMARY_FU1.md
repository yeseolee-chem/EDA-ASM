## L. learning curve (탐색)

설계: arm C, KRR·XGB(PREREG grid), 10 타깃, T1 바깥 fold 0–4, 학습 core 비율 0.25 / 0.5 / 0.75 × 반복 3(900 unit, 모두 끝남),
1.0 = 기존 T1 unit. 시험 짝은 T1 unit과 같다. 학습 core < 4 없음, gate M-1 실패 없음.

### 고른 값과 grid 끝 (`XW_report.json`, `XW_units.csv`)

| 값 | 고른 수 (50 unit) | grid 최댓값 비율 |
|---|---|---|

| learning_rate | 0.05: 40, 0.1: 10 | 0.00 (최솟값 0.05가 80 %) |

- n_estimators의 최댓값 비율 0.90 > 0.5 → **STOP 조건 충족**. `collect XW`(job 1028128)는 설계대로 종료 코드 3으로 끝났고 산출물은 모두 쓰였다.
- 최적점은 grid 바깥의 "나무 더 많이, 학습률 더 작게, 더 얕게" 쪽이다(n_estimators와 learning_rate는 서로 바꿔 쓰는 관계).

### STOP 처리 (추천 옵션; 2026-10-20 사용자 지시 "모든 선택은 추천 옵션으로 진행")

- **선택: grid를 더 넓히지 않고 X를 여기서 끝낸다.**
- 이유: (1) 이미 넓힌 효과가 para MAE 최대 6.3 %이고 CI가 0 위인 타깃은 10개 중 4개, 목표 대비 배수는 거의 그대로다. (2) 위
  비교처럼 데이터 쪽 여지(L)가 grid 쪽보다 크다. (3) 더 넓히면(예: 나무 8000–16000, 학습률 0.01–0.025, 깊이 3–4) unit 시간이
  몇 배가 되어 사전 등록 결과의 남은 경로인 SVR과 노드를 다툰다.
- 하지 않은 대안: 더 넓힌 grid로 50 unit을 다시 돌리기. 필요하면 다음 사양에서 한다.
