# G2c 요약 — G2 TS 형태 3회 탐색 중 최저 에너지 선택 (docs/specs/GEO1B.md 5)

- 날짜: 2026-11-01. 브랜치 `g2c`. 설명용이며 판정은 없다.
- 계산: D1 9,266반응과 D0 5,260반응에 autodE G2를 두 번 더 돌렸다(r1, r2). 원래 run(orig)과 합쳐 반응마다 3번이다.
  - 같은 프로토콜이다(XTB2 ALPB(water), `g2c_d1.py one` / `d0g2.py one`). first check에서 4개 root 모두 ORCA `!` 줄이 원래 run과 같았다.
  - 새 계산 29,052 run + D0 orig 복구 1,204 run. 마지막에는 동적 pool(`g2c_pool_dyn.py`, 64코어 job 10개)로 돌렸고, 재시도와 STOP은 0건이었다.
- 선택 규칙(결과를 보기 전에 정함): 성공한 run 중 `result.json e_ts_freq_eh`가 가장 낮은 것. 차이가 1e-7 Eh 이하면 orig → r1 → r2 순서. 고른 폴더 전체를 `$G2C/{d1,d0}/g2_final/<rxn_id>`로 복사했다(build job 1055745, report job 1055746).
- 사용자 결정 A-G2c(2026-10-30)에 따라 이 G2c 구조가 GEO1b의 입력이다. 그래서 명령서 5-4의 "여기서 멈춤"(GEO1c 여부를 사용자가 정함)은 해당하지 않고 GEO1b로 바로 넘어간다.

## 3. 라벨 TS 대비 (D1만, `C_rxn.csv`, `C_report.json`; 설명용)

orig와 G2c가 모두 있는 D1 8,392반응. 대칭을 고려한 라벨 대비 RMSD(Å)와 core bootstrap 95 % CI(2,000회, seed 20261030).

| | orig | G2c | 차이 95 % CI (G2c − orig) |
|---|---|---|---|
| RMSD 중앙값 | 0.269 | 0.281 | — |
| RMSD ≤ 0.25 Å 비율 | 0.487 | 0.480 | [−0.016, +0.003] |
| RMSD ≤ 0.5 Å 비율 | 0.634 | 0.622 | [−0.022, −0.001] |
| 형성 결합 오차 중앙값(절댓값, Å) | 0.0761 | 0.0759 | — |

- 형태가 실제로 바뀐 반응(G2c 대 orig RMSD > 0.30 Å): 2,224 / 8,392 = **0.265**.
  - 그중 G2c가 라벨에 0.30 Å 넘게 더 가까워진 반응 778개, 더 멀어진 반응 899개.
- 즉 xTB 에너지가 가장 낮은 형태가 DFT 라벨 TS 형태와 더 가깝지는 않다. ≤ 0.5 Å 비율은 1.2 %p 낮아졌고 CI가 0을 넘지 않는다. 형성 결합 길이는 같다.
- 판정에 쓰지 않는다. G2c를 고른 이유는 라벨과의 거리가 아니라, 배포 때 쓸 수 있는 규칙(라벨을 보지 않는 최저 에너지)으로 G2 입력을 정하는 일관성이다(사용자 2026-10-30).
