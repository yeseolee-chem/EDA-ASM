# ABS3 요약 — 반응 하나의 3채널 절대값 모델(TF · GNN · XGB) 대 짝(ΔΔ) 모델

명령서는 `docs/specs/ABS3_MODELS.md`, 결정 기록은 `results/DECISIONS.md`다. 브랜치는 `abs3`이고 ch3m 36b8e17b에서 시작했다. 단위는 kcal/mol이다.

평가 조건은 다음과 같다.
- 시험 반응: 7,491개. fold마다 그 fold의 시험 반응을 쓰며, 각 반응은 fold 하나에만 속한다.
- 시험 짝: 6개 모델의 공통 짝 7,279개. 그중 P_main · para가 1,658짝(44 core)이다.
- CI: 95 %, core 부트스트랩 2,000회, seed 20261019.

## 1. 한 줄 결론

- **Q-A**: 절대값 모델은 처음 보는 core의 반응 하나에서 barrier를 MAE 1.46–1.53(R² 0.936–0.945)으로 맞힌다.
  - 학습 평균으로 예측하면 MAE가 7.06이고, 정답 표준편차는 8.49다.
  - 가장 좋은 모델은 A-TF다.
- **Q-D**: 절대값 예측을 빼서 만든 ΔΔ는 세 모델 모두, 4타깃 모두, para와 all 모두에서 **짝 모델이 낫다**(표시 "짝 나음").
  - para 상대 차는 +12.9 %에서 +100.5 %다. strain과 barrier가 +81.3 %에서 +100.5 %로 가장 크다.
- **Q-C**: 같은 짝 두 반응의 절대값 오차는 강하게 같이 움직인다.
  - para에서 corr(e(a), e(b))는 0.64–0.85이고, 차이를 내면 절대 오차 크기의 67–76 %가 지워진다(상쇄 비율 0.24–0.33).
  - 그래도 짝 모델의 ΔΔ보다 나쁘다. 남는 오차가 짝 모델 ΔΔ 오차의 1.1–2배이기 때문이다.
  - **사전 가설 H2(짝 모델이 ΔΔ에서 더 낫다)와 맞는다.**

## 5. Q-C — 오차 상쇄와 H2 (EC_cancel.csv, P_main para)

corr(e(a), e(b)) / 상쇄 비율이다. 상쇄 비율은 평균 |e(a) − e(b)| / 평균(|e(a)| + |e(b)|)이고, 낮을수록 차이를 낼 때 오차가 많이 지워진다.

| 모델 | strain | inter | solv | barrier |
|---|---|---|---|---|
| A-TF | 0.833 / 0.248 | 0.670 / 0.322 | 0.675 / 0.326 | 0.797 / 0.249 |
| A-GNN | 0.853 / 0.238 | 0.642 / 0.328 | 0.637 / 0.332 | 0.839 / 0.242 |
| A-XGB | 0.806 / 0.267 | 0.712 / 0.311 | 0.745 / 0.304 | 0.740 / 0.311 |

**H2 해석 (표로만 보고, 검정하지 않음): H2와 맞는다.**
- 같은 계열 두 반응(a와 H 기준 b, 또는 anchor)의 절대값 오차는 상관이 0.64–0.85로 크다. ΔΔ를 만들면 절대 오차 크기의 67–76 %가 지워진다.
  - 예: A-TF strain은 반응 MAE가 1.44(a), 1.43(b)인데 ΔΔ MAE는 0.71이다.
- 그러나 반응 단위 오차(barrier 약 1.3) 자체가 짝 모델의 ΔΔ 오차(0.32–0.40)보다 몇 배 크다. 그래서 상쇄 뒤에 남는 오차도 짝 모델보다 크다(+12.9 %에서 +100.5 %).
  - strain · barrier는 상관이 대체로 높지만(0.74–0.85), 절대 오차가 커서 남는 차이도 가장 크다. 예외로 A-XGB는 barrier 상관 0.740이 solv 0.745보다 조금 낮다.
  - inter · solv는 상관이 0.64–0.74로 대체로 낮지만, 절대 오차가 작아서 차이도 작다.
- P_main all에서는 상관이 0.43–0.67로 낮고 상쇄 비율이 0.36–0.48로 높다.
  - 짝 모델과의 차이는 +11.4 %에서 +51.5 %로 para보다 작다.
  - 다만 12칸 중 11칸에서만 그렇다. A-XGB solv는 all +15.3 %가 para +14.5 %보다 크다.
- 데이터가 약 7,500반응으로 DeepDelta 기준(< 1,500)보다 크지만, 짝 모델의 이점은 여전히 남았다. 데이터 크기에 따른 변화는 이 실험에서 보지 않았다.

## 8. 편차 · 구현 결정 목록

1. **C-O 기준**: "각 타깃 표준편차"를 그 64개 반응의 표준편차(ddof 0)로 읽었다. fold 0 학습 반응 전체의 표준편차도 C_part_gpu.json에 함께 적었다.
2. **H 기준 반응 정의**: reference 짝의 b 반응을 H 기준 반응으로 정했다(147개). 라벨 파일의 attach가 "direct"라서 부착 direct 묶음에 함께 들어간다.
3. **XGB yhat_seed_sd**: fit이 한 번이라 반응 표와 짝 표 모두 NaN이다.
4. **Q-D 표시**: p와 all 행에만 붙였다(CH3M과 같음). m 행은 설명용이다.
5. **selftest(8-6)의 "EM_rank 세 행"**: GNN3 · TF3 · XGB3의 para 행으로 읽었다. EM_metrics P_main para MAE 행과 함께 소수 넷째 자리까지 모두 재현했다(공통 짝 7,279).
6. **XGB 예측**: `predict` 결과(float32)를 float64로 바꾼 뒤 μ + s · ŷ로 kcal을 만들었다.
7. **K 제출**: 최대 병렬로 GNN · TF · XGB 배열을 함께 냈다. 수집 · E만 `afterany` / `afterok`로 이었다.
8. **코드 리뷰(5관점 workflow, 반박 검증 포함)에 따라 개발 단계에서 고친 것**(결과 commit 전): 실행기 재제출 안전성, C 병합 입력 대조(pack · LS sha256), XGB C-T X 통계 대조, PREREG 재실행 no-op과 코드 commit 확인, STOP 종료 코드 3 통일, C-5의 "시험 반응이 inner 집합에 없음" 명시 확인.
9. **개발 시험 실행 2회**: `$ABS3/dev`에서 실제 데이터로 돌렸다. 결과가 아니며 commit하지 않았다.
