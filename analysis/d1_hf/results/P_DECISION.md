# D1-HF Phase P 뒤 결정 (명령서 6절의 사용자 결정 2건)

사용자 지시(2026-10-21, 명령서를 받은 직후): "모든 분기는 너의 추천대로 진행". 그래서 아래 두 결정은 추천안을 택한 것이며, 보고용으로 여기에 기록한다.
파일럿 판정은 통과했다(`P_REPORT.md`, `P_metrics.json`).
- ok 100 / 100, 재시도 0
- ok 행의 판정 gate 100 %이며, 명령서 기준(0.01 / 1e-3)으로도 100 %
- S-1 통과

## 1. 본계산 시작 — 시작한다

- 판정 조건(ok ≥ 95 %, gate 100 %, S-1 통과)을 모두 만족한다.
- 예상 비용(`P_metrics.json`)은 대상 9,266개 전부에 약 1,355 코어시간이다. 반응당 중앙값은 0.106 코어시간이다.
- 1,000개 이하 배치마다 점검한다(`build.py check`). 점검 하나라도 STOP이면 새 배치를 시작하지 않는다(`build.py gate_prev`).

## 2. G1 구조로도 EDA — 한다

- 명령서 9절 한계: "라벨 구조(DFT TS)에서 계산했으므로, 새 반응 예측에 쓰려면 G1 구조 계산이 필요하다."
- 파일럿 (나)에서 HF@G1과 HF@DFT-TS의 차이가 컸다(86반응).

  | 항목 | MAE (kcal/mol) | r |
  |---|---|---|
  | bond | 8.4 | 0.37 |
  | elst | 8.1 | 0.66 |
  | pauli | 16.6 | 0.63 |
  | oi | 11.4 | 0.57 |

  따라서 DFT-TS 값만으로는 G1 구조 위의 입력을 대신할 수 없다.
- 비용이 작다. EDA 1개의 코어시간 중앙값은 0.085로, G1 구조가 있는 대상 약 8,400개에 약 700 코어시간이다.
- 범위는 명령서 7절대로 EDA 1개(`geom = g1`)이고, 같은 조각·전하를 쓴다. 원자 순서와 원소가 DFT TS와 다른 반응은 뺀다(`prep.py main`, `M_g1_inputs.csv`).
