# 배포 경로 평가 — GEO1b 보정 구조 → LADDER dft rung 에너지 모델

- 날짜: 2026-11-03. 브랜치 `geo2b`. 코드 `analysis/geo2/deploy/`, 규칙 `results/DECISIONS_deploy.md`(DP-1..6, 결과를 보기 전에 기록).
- 배포 경로: SMILES → xTB TS(G2c) → GEO1b 구조 보정 → **LADDER dft rung 모델**(DFT 라벨 TS 입력으로 학습한 40 단위) → 8채널 + d1·d2·c_ghost·barrier. 두 모델은 이미 학습돼 있었고, 이어서 잰 적은 없었다.
- 다시 학습한 것은 없다. 원자 모델(AW·GNN·TF)은 저장된 가중치를 그대로 쓰고, XGB는 저장된 모델이 없어 LADDER와 같은 데이터·seed·설정으로 다시 맞췄다(재현 검사로 확인).
- 시험: D1 T1 시험 짝 중 dft와 geo 입력이 모두 있는 7,540짝(P_main para 1,697). fold k는 fold k를 학습하지 않은 dft 단위가 예측하고, 그 구조도 fold k를 보지 않은 GEO1b final_f{k}가 만들었다(누수 검사 0건).
- 대표 선택(REP, REP8, ENS4)은 dft rung이 자기 내부 검증으로 고른 것을 그대로 쓴다. 시험 결과로 다시 고르지 않았다.

## 3. 왜 이렇게 나빠지나 (입력 이동, `results/DEPLOY_input_shift.csv`)

- dft rung 모델은 DFT 라벨 구조에서 계산한 입력(HF 기준선, X182, 원자 token)으로 학습했다. 그래서 정답에 아주 가까운 구조 정보를 전제로 한다. (a)의 오차가 매우 작은 것도 이 때문이다.
- GEO1b는 형성 결합 길이를 고쳤지만(오차 중앙값 0.078 → 0.025 Å) 형태(conformer)와 나머지 결합은 G2c(xTB) 그대로다. 반응물 기준 구조도 xTB(G2c rel1/rel2)다.
- 그 결과 변형 에너지 계열(d1, d2, barrier)의 HF 입력이 크게 달라진다(평균 +21–32 kcal/mol, r 0.24–0.40). EDA 채널의 입력도 평균이 움직였다(oi +6.3). dft 모델은 이런 입력을 학습 중에 본 적이 없어서 SH arm(β·ΔH 기준선)을 중심으로 크게 틀린다.
- 결과적으로 dft rung 모델은 배포 입력(xTB 기반 보정 구조)으로 옮겨 쓸 수 없다. 배포 입력으로 학습한 GEO2b 모델(c)이 이 경로에서는 더 낫다. 다만 (c)도 LADDER 목표에는 못 미친다(oi 0.993, cpcm 0.370).
