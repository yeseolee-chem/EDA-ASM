# GEO2b 요약 — 보정 구조(rung geo)로 D0 + D1 에너지 모델 학습

- 날짜: 2026-11-03. 브랜치 `geo2b`. 사전 등록 `results/PREREG_GEO2B.md`(commit 4db2121a, 학습 전).
- 사용자 결정 D0D1(2026-10-31): AW·GNN·TF·XGB × arm S/SH × 5 fold(40 단위)를 rung geo에서 D0+D1 짝으로 한 번 학습한다. **비교 모델과 판정은 없다.** D1과 D0는 따로 보고하고 합치지 않는다. 절대 기준은 LADDER 목표 하나다.
- 파이프라인: SMILES → G2c(autodE 3회 중 최저 에너지 TS) → GEO1b 구조 보정(D0·D1 모두 자기 fold를 보지 않은 모델) → Z(구조 폴더) → G(xTB Freq) / F(X182 + token) / H(HF/6-31G* EDA) → P(입력 표) → M3 학습 → E 평가.

## 5. 편차와 기록 (모두 결과를 보기 전에 정하고 DECISIONS에 적음)

- **E2-rule** (GEO1b E2 sanity 0.0255 > 0.02, azide N–N): Z 좌표를 3 seed 평균 → 통과한 seed 평균 → 통과한 seed 하나 → G2c 순서로 골랐다(analysis/geo1b/results/DECISIONS.md, DECISIONS_ZE.md).
- **F-1 accept**: D1 feature 실패 1.27 %(선례 1.14–1.42 %). 120반응이 rung geo에서 빠졌다(DECISIONS_feat_runtime.md).
- **M3-cap**: smoke 예상 162.2 GPU-h > 설계 상한 160 → 200으로 올렸다(DECISIONS_lad.md). 실제 사용은 약 42 GPU-h였다.
- **꼬리 병렬화 사고**: 마지막 짧은 두 단위를 다른 GPU 종류에서 따로 돌렸다. 원래 task의 캐시 확인(GPU까지 비교)이 STOP해 collect가 한 번 취소됐다. collect는 GPU를 빼고 비교하므로 다시 학습하지 않고 collect·확인·평가만 다시 냈다(DECISIONS_lad.md).
- **Y 지연**: GEO1b Y를 약 3–5시간 늦게 냈다(점검이 돌지 않은 시간).

## 6. 한계 (사전 등록 6절 요약)

- 구조 모델의 fold 교차 의존(학습 짝 구조를 만든 모델이 시험 fold의 라벨 TS를 학습)이 D0까지 걸친다.
- D1 시험 core와 같은 종류의 D0 반응이 학습에 들어간다(데이터셋 간 전이). D1의 '보지 못한 core' 주장은 약해진다.
- D0에는 Phase V(DFT 형태 탐색)가 없다. D0 라벨 TS는 Gaussian 16, D1은 ORCA다.
- 비교 모델이 없어 D0가 D1 정확도를 돕는지 해치는지는 이 실험으로 알 수 없다.
