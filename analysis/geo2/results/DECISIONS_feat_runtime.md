# GEO2b feat_geo 실행 결정 기록 (feat_geo.py DECISIONS; 사람이 쓴 판단 기록은 DECISIONS_feat.md)

- **feat_geo/GEO-1 base**: 기준 집합 = 결합 라벨($GEO2B/comb/labels_d0d1.json: D1 9,266 + D0 5,255) 중 $GEO2B/geo_final/<rxn_id>/.done인 반응 전부(job_id 순서). 전제: results/Z_report.json stop false·complete true(없음·running·complete 아님 = exit 2, stop = exit 3)이고 Z_status.csv ok/kept 행 = Z_report n_folders(정수 또는 dataset별 정수의 합) = .done 표지. 대체(fallback) 폴더도 .done이므로 들어간다(명령서 0-2). D1 rxn_id >= 1,000,001, D0 0..5973(5,255행)이라 rxn_id 범위로 dataset을 정한다.
- **feat_geo/GEO-2 G slices**: G = 'g <i|A> <n>'(LADDER g0f0 g0 방식): 기준 반응(job_id 순서)의 i::n 조각에 feat.py의 g_one / run_pool / order_g를 쓴다(조각마다 canary·abort·바이트 예산 2 GB). 조각은 stale만 STOP, 남은 반응이 있으면 exit 2. 명령서 6-2 G 비율은 g_report가 dataset마다 전체 기준 집합에서 계산하고 f_* / p / report가 다시 확인한다. 'retry'는 그 조각의 .fail_freq_* / .fail_error_* / stale 폴더만 옮긴다(명시적일 때만).
- **feat_geo/F-1 feature root**: feature 루트 = $GEO2B/geo_feat/<rxn_id>(G1 폴더 형식): geo_final의 ts.xyz·rel1.xyz·rel2.xyz 바이트 복사 + result.json·work/ts.hess(XTB2 ALPB(water) Freq). geo_final은 Z가 만든 그대로 두고 사본에 쓴다(D1-G3 F-1). 사본의 sources sha256이 지금 geo_final 파일과 다르면 stale = STOP. D1-HF는 geo_final을 읽는다(D1HF_G2_ROOT).
- **feat_geo/F-2 G step**: work/ts.hess = g0f0 G0 경로(FREQ_HEADER nprocs 1, %maxcore = config_g2 maxcore_mb; orca_direct; g0f0.hess_atoms; run_ts.forming_share(라벨 형성 결합); TOL_HESS_GEOM_A 1e-4; canary·abort·바이트 예산). 전하 = 라벨 charge1 + charge2(D0의 전하 반응 260개 포함), mult 1. 원자 순서 gate의 기준 파일 = $GEO2B/comb/jobs/<job_id>/{ts, ref_dipole, ref_dipolarophile}.xyz(D1 = d1_jobs, D0 = d0_g2 labjobs = Coley 파일의 바이트 사본, Phase X X-2가 확인). 역할 dipole/dipolarophile은 두 dataset 모두, rel 파일 이름(ref_dipole / ref_dipolarophile.xyz) 검사는 D1만(D0 라벨의 rel 파일 이름은 Coley 이름). n_imag 0 / >= 2는 .done(G0-4, 명령서 6-2).
- **feat_geo/F-4 gate**: 명령서 6-2 STOP 기준을 dataset(D1, D0)마다 따로 적용한다(GEO-16). G(g_report): 원자 순서(순서 gate + ts_fragments) > 기준 반응의 0.5 %, Freq / 오류 > 1 %, B6 계산 불가 > .done의 1 %, stale. F(G .done 수 기준): F-1(유한한 182열 행 없음, B6만 실패 포함 = g0f0 f0_report) > 1 %, B6 > 1 %, Q-a > 1 %, T-a > 1 %, FU2 gate 자체의 STOP, mergeroot stop, 개수 불일치, 토큰 배치 != D1PAIR g1, G의 B6 예측 != F status_B6. H: 실행 실패 / 끝난 반응 > 1 %(GEO-6), 입력 검사 실패 > 1 %, rel 에너지 gate(GEO-5) > 0.5 %. n_imag 0 / >= 2는 실패가 아니다.
- **feat_geo/F-5 F layout**: F = g0f0 F0 구조: f_slice <i> <n> -> f_atoms <i> <n>(선택, 배열) -> f_rest(f_merge, f_atoms 0 1(캐시), f_gate(err.json 재시도 1회 + _qgate), f_tokens, f_report). 버전 fu2-atoms-3-geo / fu2-tokens-3-geo; D1G2_SCRATCH=$GEO2B는 d1_features 자식 환경에만(F0-2); 입력 = 결합 입력(--labels/--meta/--prof = $GEO2B/comb, GEO-12). root_fp.json·ids_all.csv는 f_slice가 $GEO2B/locks/F_geo.lock 안에서 쓴다.
- **feat_geo/F-6 HF**: D1-HF runner의 g2 자리를 geo로: D1HF_SCRATCH=$GEO2B/hf_geo, D1HF_RES=results/hf_geo, D1HF_TEMPLATES=$GEO2B/comb/hf_templates(D1 -> d1_hf/inputs/<T>, D0 -> Phase X 템플릿; 읽기만), D1HF_G2_ROOT=$GEO2B/geo_final. D1-G2 phase_fh H 구조: h_inputs <W>(_geominputs 한 번 -> 입력 ok 반응을 (n_atoms, job_id) round robin, nb = W x ceil(n / (1000 W)), worker k = j % W; pilot 목록) -> h_pilot -> h_batch <k> <W>(run.py run, 큰 반응 먼저, $SLURM_CPUS_PER_TASK개 직렬 ORCA; 배치마다 build.py check) -> h_build(_allgeom) -> h_report. SlowConv 재시도 1회는 run.py 그대로.
- **feat_geo/GEO-4 pilot**: pilot = dataset마다 25반응(D1 25 + D0 25 = 50): 입력 ok 기준 반응을 dataset마다 (n_atoms, job_id) 순으로 4등분(np.array_split)하고 사분위마다 6, 6, 6, 7개를 default_rng(20261024)로 뽑는다; D0 사분위에 전하 반응이 있으면 그중 1개는 전하 반응. 예상 = Σ_(dataset, 사분위) (pilot 평균 반응당 코어시간 x 그 칸의 입력 ok 반응 수)(층화 추정). 상한 4,000코어시간(D0D1 결정; 명령서 6-1의 2,500은 D1만이었다). 초과·유한하지 않음 = STOP. 반응당 코어시간 = timing.tsv wall_seconds 합(직렬 ORCA). D1-G2 보정 예상은 정보. rel gate를 pilot에도 적용. h_batch는 지금 plan의 통과한 H_pilot.json이 있어야 돈다.
- **feat_geo/GEO-5 rel gate**: 명령서 6-1 HF 추가 gate를 A-G2c에 맞게 좁힌다: 비교 대상 = D1 반응 중 G2c C_select.csv chosen == 'orig'(G2c 폴더 = 단일 run D1-G2 폴더의 사본)이고 geo HF ok이며 analysis/d1_g2/results/labels_d1_hf_g2.parquet에 ok 행이 있는 반응. geo_final rel1/rel2.xyz sha256이 d1_g2/g2_final의 것과 다르거나 e_frag{k}_rel_eh 차이 > 1e-6 Eh면 불일치. 불일치 / 비교 반응 > 0.5 % = STOP. r1/r2가 뽑힌 D1과 D0에는 기준이 없다(보고만). C_select.csv에 G2c 선택(orig/r1/r2)이 없는 D1 geo 반응이 있으면 STOP(검토 R-3: 비교 대상이 비어 gate가 그냥 통과하지 않게).
- **feat_geo/GEO-6 H run failure**: 명령서 6-2 H '실행 실패 > 1 %' = (H_status fail + gate_fail + eda_table_unexplained + parse_fail) / 끝난 반응, dataset마다. h_batch의 배치 누적 검사(M_checks)는 두 dataset을 합친 비율로 미리 멈춘다(가중 평균 > 1 %면 어느 한 dataset이 > 1 %이므로 잘못된 STOP이 아니다).
- **feat_geo/GEO-7 accept**: F rate STOP(F-1, B6)을 사용자가 받아들이면 'p --accept=F-1[,B6]' / 'report --accept=...' / 'g_report --accept=B6'가 그 rate 규칙만 accepted_stops로 옮긴다. 기본값은 STOP, 다른 STOP은 받아들일 수 없다.
- **feat_geo/F-7 P tables**: 입력표 = inputs.py 함수 그대로(inputs.RUNGS['geo'] 고정값 = rung_cfg('geo'), GEO-8): Phase Q 준비(F-13) + D0 Q 준비(Q_d0_report.json all_pass·stop false·Q_keys_d0 sha256), _read_h, refs_min(Q-2 키 = D1 Q_keys.parquet + D0 Q_keys_d0.parquet 이어 붙이기; 키별 최저 HF 기준; P6b는 각 행의 키 formula·WL hash), assemble_rung(P-a + 재조립), token_info(g1 배치), make_table(결합 대상 14,521행), table_summary -> $GEO2B/inputs/geo.parquet, results/P_build_geo.json. 전제: G·G report·F·H gate가 STOP 없이 complete.
- **feat_geo/F-7b constrained keys**: 제약 키(Q_keys constrained: D1 = '|fixed:' 회전 막힌 dipole, D0 = alt 기준 구조 '|cfg:')는 g2 rung의 P20 (c)와 같이 교체하지 않고 자기 기준을 쓴다(DFT 기준 구조에서 나온 상태가 geo H 값에 들어가지 않게). refs_min 결과에서 constrained 행의 'min' 교체를 되돌린다(references_g3_cons_own).
- **feat_geo/GEO-8 P registration**: inputs.py RUNGS['geo']는 명령서 8-1대로 고정이고, cmd_p는 rung_cfg('geo')와 문자열 값으로 같은지 확인한다(다르면 STOP). 키 targets(결합 라벨)·keys(D1 + D0 Q 키 파일)는 geo에만 있다.
- **feat_geo/GEO-9 pair sets**: 명령서 7(D1): 짝 universe = D1PAIR S_folds.csv, P_<rung> = a·b 모두 usable. P_dft·P_g2는 LADDER 표에서 다시 계산해 LADDER 집합 파일과 같아야 한다. P_23 = P_g2 ∩ P_geo, P_023 = P_dft ∩ P_g2 ∩ P_geo. |P_23| < 0.98 |P_g2|(전체 또는 P_main 기준 짝)이면 STOP: D0D1 결정으로 geo-g2 판정은 없지만, geo가 g2 위에 만든 것이라 반응을 잃지 않았는지 보는 파이프라인 검사로 남긴다. D0: $GEO1B/d0/D0_pairs.csv (D0_pairs_report.json stop false, sha256, g2_source g2c; 예비판이면 exit 2), usable 짝 = 두 끝 usable + ok, fold(d0_folds.csv)·edge_kind별 수, 끝이 usable이 아니라 잃은 짝과 이유. dataset·fold별 usable 반응 수.
- **feat_geo/F-8 T-2**: T-2 = 1000003, 1000019, 1000614: $LAD/dft_final 바이트 복사 -> G 단계 코드 -> runroot/mergeroot(결합 입력) -> 182열 vs X182_d1_dft(1e-8; D1-G2 T-1 선례 scan_curv_* <= 2.5e-7 = pass_f0_precedent) + 토큰 sha256 vs F0_tokens_manifest.csv(FU2_X182 = X182_d1_dft 세 행 사본, 버전 -dft). 결합 입력의 D1 행이 G2 입력과 같은 결과를 내는지도 이것으로 확인한다. 작업 폴더 $GEO2B/t2.
- **feat_geo/F-9 T-3**: T-3 = 이 파일의 H 경로(_geominputs -> run.py -> _allgeom -> parse_rxn), D1HF_G2_ROOT = $LAD/dft_final, D1HF_TEMPLATES = 결합 템플릿, T00003·T00019·T00614 vs labels_d1_hf.parquet geom=dft(<= 1e-6 kcal/mol) + labels_d1_hf_g2.json 행 일치. 작업 폴더 $GEO2B/t3.
- **feat_geo/F-10 T currency**: g / g_report / f_* / h_* / p는 T_2·T_3·T_d0f·T_d0h.json이 지금 코드(CODE_REL sha256 묶음)로 통과했을 때만 돈다(없음·실행 중·코드 바뀜 = exit 2, 실패 = exit 3).
- **feat_geo/F-11 decision log**: 모든 명령이 시작할 때 이 결정을 results/DECISIONS_feat_runtime.md에 'feat_geo/<키>'로 적는다(fcntl 잠금 $GEO2B/locks/DECISIONS.lock). results/DECISIONS.md는 다른 역할도 쓰므로 이 파일은 쓰지 않는다.

- **feat_geo/GEO-10 removed**: D1-G3의 Part A·Phase O·U-1 논리와 결정(F-3, F-14, U-2f-*)은 해당하지 않아 지웠다.
