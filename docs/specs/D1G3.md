# D1-G3 — G2 TS를 값싼 방법으로 다시 최적화하는 시범(HF/6-31G\* 대 r2SCAN-3c) + TS 형태 확인 — Claude Code 실행 지시서

**저장소:** `d1-ladder` HEAD(`dcd83ab3` 이후)에서 새 브랜치 **`d1-g3`**를 만든다.
**이 파일:** `docs/specs/D1G3.md`로 commit한다.
**새 코드:** `analysis/d1_g3/` · **결과:** `analysis/d1_g3/results/` · **scratch:** `/gpfs/tmp_cpu2/yeseo1ee/d1_g3/` (이하 `$G3`)
**순서:** 0(시작 조건) → S(표본) → T(회귀 검사) → O(TS·기준 구조 최적화) → F(feature·HF EDA) → E(평가) → R(보고). Phase B(TS 형태 확인)는 S 뒤에 **따로 병행**한다.
**사용자 승인으로 멈추는 곳은 없다.** 12절 STOP 조건에서만 멈추고 묻는다. 버그를 찾으면 고치기 전에 보고한다.
**학습은 하지 않는다.** 이미 학습된 D1LADDER 모델을 새 입력에 적용만 한다.

## 0. 무엇을, 왜

- D1LADDER 결과(`d1-ladder` `dcd83ab3`):
  - 라벨 DFT TS 구조 위 입력(dft·SH)은 단계 2 목표를 통과했다(REP oi para 0.102, cpcm 0.060).
  - SMILES → xTB 구조(g2)는 oi 1.04–1.09로 미달이다.
  - g2 오차는 두 갈래다.
    - **TS 형태가 다른 경우:** G2가 G1과 같은 TS를 찾은 짝은 oi 0.73, 다른 짝은 2.14였다.
    - **구조 정밀도:** 같은 xTB feature가 DFT 구조에서는 oi 0.17, xTB 구조(g1)에서는 0.69였다.
- **Part A (Phase O·F·E):** G2 TS를 값싼 방법으로 다시 최적화하면 dft rung에 가까워지는가? 두 방법을 같은 표본·같은 출발 구조로 비교한다.
  - **g3h:** HF-D3BJ/6-31G\*, SMD(water)
  - **g3r:** r2SCAN-3c, SMD(water) (Grimme et al., J. Chem. Phys. 2021, 154, 064103, doi:10.1063/5.0040021)
- **Part B (Phase B):** G2가 라벨과 다른 TS 형태를 찾았을 때, 라벨 수준에서 어느 쪽 TS의 에너지가 더 낮은가? 라벨 자체의 TS 선택 잡음을 처음으로 잰다.
- 이 명령서는 **시범**이다. 판정 규칙은 9절에 미리 고정한다.

## 4. Phase O — 최적화 (Part A·B)

### 4-1. Part A: TS (반응 × 방법 g3h, g3r)
- 시작 구조: `$G2/g2_final/<rxn>/ts.xyz`. 전하·다중도는 라벨과 같다.
- **g3h 키워드:** `! HF D3BJ 6-31G* TightSCF OptTS Freq`, `%cpcm smd true smdsolvent "water" end`
- **g3r 키워드:** `! r2SCAN-3c TightSCF OptTS Freq`, 같은 `%cpcm` 블록
- 둘 다 `%geom Calc_Hess true Recalc_Hess 5 MaxIter 200 end`(G1·G2와 같은 블록). ORCA 6.1.1.
- **TS gate:** G1·G2에 쓴 TS 판정 함수(허수 진동수 규칙, 형성 결합 범위, 결합 그래프)를 그대로 쓴다.
- **재시도:** 실패하면 `Recalc_Hess 1 MaxIter 300`으로 한 번만 더 돈다. 그래도 실패면 `.fail_<이유>`.
- **형태 유지 판정:** 최적화된 TS가 출발한 G2 TS와 같은 TS인지(같은 규칙) 기록한다.

### 4-2. Part A: 반응물 기준 구조
- G2 `rel1.xyz`, `rel2.xyz`에서 출발해 같은 방법으로 `Opt Freq`(허수 없음).
- 같은 분자 키(D1LADDER Phase Q 키 규칙)는 한 번만 계산하고 같은 결과를 쓴다.

### 4-3. Part B: 라벨 수준 TS 확인
- 시작 구조: G2 TS. 수준: D1 autodE가 TS에 쓴 것과 같은 키워드(B3LYP-D3BJ/def2-SVP, SMD(water)). D1 run config의 `opt_ts`·`hess` 키워드를 그대로 가져온다. ORCA 6.1.1. TS gate는 D1과 같다.
- 결과 TS가 라벨 TS와 같으면(같은 TS 규칙) `converged_to_label`로 기록한다.
- 아니면 라벨 수준 단일점(def2-TZVP SMD, 라벨 입력에서 좌표만 바꿈; T-5 방식)을 계산한다.
- **보고 값:** ΔE‡ = E(G2 형태 TS) − E(라벨 TS) (kcal/mol, 같은 SP 수준)

### 4-4. 출력
- `$G3/g3h_final/<rxn>/`, `$G3/g3r_final/<rxn>/`: G1 폴더 형식(`ts.xyz`, `rel1.xyz`, `rel2.xyz`, `result.json`, `.done` / `.fail_*`)
- `$G3/partB/<rxn>/`
- `results/O_status.csv`: rxn_id, 방법, 상태, 이유, 허수 진동수, 형태 유지, 코어시간

## 5. Phase F — 새 구조 위 입력 (Part A)

- **feature:** `work/ts.hess`(feature B6)는 G0와 같이 최적화된 TS에서 ORCA `! XTB2 ALPB(water) Freq`(최적화 없음)로 만든다. 그다음 전역 182와 FU2 원자 토큰을 D1LADDER G0·F0 경로(루트 = `$G3/g3h_final`, `$G3/g3r_final`)로 계산한다. 버전 이름은 `fu2-atoms-3-g3h`/`-g3r`.
- **HF EDA:** D1-HF runner로 5개 계산. `eda`와 `frag*_dist`는 새 TS에서, `frag*_rel`은 4-2의 새 기준 구조에서 가져온다(`geom = g3h`/`g3r`).
- **입력표:** D1LADDER Phase P와 같은 규칙으로 `$G3/inputs/g3h.parquet`, `g3r.parquet`를 만든다. H의 d1·d2·barrier는 rung 안 분자별 최저 기준으로 조립한다.
- **gate:** F0·D1-HF gate를 그대로 적용한다. 실패한 반응은 빼고 수를 보고한다.

## 6. Phase E — 평가

모든 표에서 같은 짝에 대해 dft·g1·g2(D1LADDER 기존 입력)와 g3h·g3r을 나란히 놓는다. 분류(`same`, `different`)별로 따로 보고한다.

| # | 무엇을 | 지표 |
|---|---|---|
| E-1 | 구조: 라벨 DFT TS와의 차이 | 형성 결합 2개의 반응 단위 차이 (중앙값·90 %), **짝 단위 차이** Δdd = (d_a − d_a,DFT) − (d_b − d_b,DFT), 무거운 원자 RMSD(D1 검증 `rmsd.py`), 라벨과 같은 TS 비율 |
| E-2 | **짝 구조 잡음:** HF 채널 | 채널마다(elst, pauli, oi, disp, cpcm, cds, d1, d2, barrier) \|ΔΔ_HF(새 구조) − ΔΔ_HF(DFT 구조)\|의 중앙값·평균 (para) |
| E-3 | **처음부터 끝까지:** 학습된 모델에 새 입력 | 각 짝은 자기 T1 fold의 unit 모델로 예측한다(누출 없음). 모델: dft·SH, dft·S(주), g2·SH, g2·S(참고). 대표 모델은 D1LADDER `E2_report.json` representatives(rung·arm·타깃별)를 그대로 쓴다. 지표: 9 타깃 para MAE와 core 단위 bootstrap 95 % CI(2,000회, seed 20261019). LINE(β = 그 fold unit의 β) 포함 |
| E-4 | **회복률** | 회복률 = (MAE_g2 − MAE_g3) ÷ (MAE_g2 − MAE_dft). 같은 짝, 같은 모델 계열(dft·SH 대표)에서 oi, cpcm, barrier |
| E-5 | 비용·성공 | 방법별 TS 성공률, 형태 유지율, TS 하나당 코어시간(중앙값·평균), 기준 구조 코어시간. 라벨 TS 단계(파일럿 평균 8.2 코어시간/반응)와 비교 |
| E-6 | Part B | 라벨 수준 ΔE‡ 분포: ΔE‡ < −0.5(G2 형태가 더 낮음, 라벨이 최저가 아님), \|ΔE‡\| ≤ 0.5, > 0.5(라벨이 더 낮음), converged_to_label 비율. dipole별로도 |

- 출력: `results/E_geometry.csv`, `E_noise.csv`, `E_endtoend.csv`, `E_recovery.csv`, `E_cost.csv`, `B_energies.csv`, `results/E_report.json`.
- 그림 `results/figures/`:
  - `figG3_1_noise`: E-2 채널별 짝 구조 잡음, 방법 × 분류
  - `figG3_2_endtoend`: oi·cpcm·barrier para MAE, 입력 g2·g3h·g3r·dft, 분류별
  - `figG3_3_partB`: ΔE‡ 히스토그램

## 7. 계산량과 비용

- Part A: 표본 짝 100개 → 고유 반응 약 200 이하 × 2방법 TS + 기준 구조(분자 키 단위) + xTB Freq + HF SP 5개.
- Part B: 40반응 × (라벨 수준 TS 최적화 + 단일점).
- O 단계 시작 전에 반응 5개(g3h, g3r 각각)와 Part B 2반응을 먼저 돌려 코어시간을 재고, 전체 예상을 보고한다. **예상 합계가 3,000 코어시간 이하**이면 자동으로 진행하고, 넘으면 STOP.

  - D1 run·job 폴더

## 9. 판정 (결과 보기 전에 고정)

Part A는 방법마다 `same` 분류에서 판정한다.
- **본격 진행 권고 (go):** 아래 셋을 모두 만족.
  - ① E-4 oi 회복률 ≥ 0.8, 그리고 dft·SH 대표의 oi para MAE ≤ 0.20
  - ② TS 성공률 ≥ 0.9, 형태 유지율 ≥ 0.9
  - ③ TS 하나당 코어시간 중앙값 ≤ 2.0 (라벨 TS 단계 평균 8.2의 약 25 %)
- **부분:** ①만 만족 → 정확도는 되지만 비용이나 안정성이 문제다.
- **불가:** ① 불만족.
- 두 방법이 모두 go이면 코어시간이 적은 쪽을 권고한다.
- `different` 분류의 결과는 설명용이다. TS 형태가 달라 회복을 기대하지 않는다.
- **Part B 해석 (설명용):**
  - ΔE‡ < −0.5인 반응 비율이 0.2 이상이면 "라벨 TS가 최저 TS가 아닌 경우가 많다. TS 형태 탐색을 라벨과 입력 모두에서 강화해야 한다"고 쓴다.
  - 0.2 미만이면 "G2가 더 높은 TS를 고르는 것이 주원인이다. 입력 쪽 TS 형태 탐색을 강화해야 한다"고 쓴다.
